## How I build

Most people vibe-code a product in a few hours and push it live.
I don't.

Before a single line generates, there's a plan — architecture, data flow, edge cases. Then it builds. Then it gets tested hard: security, performance, user experience, failure states. Prompts get rewritten. The flow gets tightened. Then it gets tested again. Only then does it ship.

AI doesn't hallucinate in my workflows because I don't give it room to. Every output gets challenged, every component gets reviewed, every user path gets walked. The result isn't just a working product — it's a clean one.
